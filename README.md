# claude-plugins

Claude Code plugins by Min-An Yang (minanyang).

```
/plugin marketplace add minanyang/claude-plugins
/plugin install 10x@minanyang
/plugin install nameable@minanyang
```

| Plugin | What it is |
|---|---|
| [10x Agent](https://github.com/minanyang/10x-agent) | A multi-agent workflow for shipping code: agents plan, build and review, and nothing lands without evidence a script can check. |
| [nameable](https://github.com/minanyang/nameable) | Is the name really free? Nameable checks every registry, store and domain your project needs. |
